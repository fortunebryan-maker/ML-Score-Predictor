#Machine Learning Score Predictor

This project uses Linear Regression to predict a student's score based on the number of hours they studied.

#Features included
- Data splitting
- Model evaluation using MAE, MSE, RMSE and R**2 Score
- Visualizations using Matlotlib

##Results
- **Model Accuracy (R^2):** 0.9678
- **Example Prediction:** Studying for 5 hours predicts a score of roughly 51
